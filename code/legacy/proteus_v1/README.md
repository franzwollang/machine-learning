# Proteus v1 Legacy Prototype

This folder is a copy of the pre-rewrite codebase.

It is useful as reference material for:

- early Stage 1 scaffold experiments;
- circle and Swiss-roll dataset fixtures;
- Gaussian node-efficiency diagnostics;
- hierarchy comparison visualizations.

It is stale relative to the current Proteus Paper 1 SI. In particular, it does not implement the current scale-response controller, AP/smoothed-PMI clustering, Dirichlet--multinomial evidence gate, Stage 2 complex construction, torsion diagnostics, dual-flow density reconstruction, or canonical fuzzy membership interface.
